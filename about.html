Aman Kumar

Developer building local-first tools that people keep installed.

I am Aman Kumar, a software developer. I write software that runs on your machine, keeps your data there, and does one job well. That constraint is the whole idea: the tool should still be useful in ten years, on a laptop with no network.

I publish most of this work on GitHub as AMANKUMAR7777. The repository list is the best record of what I have actually shipped, including the projects that never made it to this site.

I learned to program by breaking things on Fedora and reading the source of the tools I broke. That habit is still how I work: read the code, find the seam, change one thing, check what moved. It is slower at the start and faster by the end.

Projects

What I have shipped

Each project below started as a personal annoyance and ended as something you can run.

SiftAI is a universal file organizer driven by a local language model. You point it at a messy Downloads folder, it proposes a structure, and then it moves files into it. It never deletes anything without keeping a copy. Written in Python, fully local, no cloud round trip. Source on GitHub.

PDS — Paper Drive Storage encodes any file into a printable A4 pixel grid and decodes it back with a camera. It treats paper as cold storage: slow, boring, and readable without a computer. Source on GitHub.

GLSL-Stress is a ray-marching GPU stress test with live-editable fragment shaders. It exists because a graphics card is easier to understand when you can watch it struggle. Live demo.

Smaller utilities run alongside them: sys-mon, a terminal resource monitor that is pleasant to leave open, and fapt, short commands for the apt workflows I type every day. sys-mon · fapt.
